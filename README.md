HCS DataExploreR

High-content screening and microplate data analysis and visualization tool

Run app.R to launch R Shiny app

Data Privacy: HCS DataExploreR processes uploaded data in session-specific R memory. Uploaded data are not written to disk or stored outside the active session.

Online Tool: https://joseph-chao-hcsdataexplorer.share.connect.posit.cloud/
Data Persistence Policy: For information about data handling and persistence when uploading data to the online tool, please refer to Posit Connect Cloud’s Data Persistence Policy (https://docs.posit.co/connect-cloud/user/platform/system.html)
